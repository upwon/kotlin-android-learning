# Kotlin Android 学习站

面向 Java Android 开发者的系统 Kotlin 学习网站。课程从 Java → Kotlin 思维迁移开始，逐步覆盖类型系统、常用写法、泛型、JVM 互操作、协程、Flow 与 Android 实战。

## 当前内容

- 8 个知识部分、29 章完整课程地图
- 第 1～4 章完整讲义
- Java / Kotlin 对照代码与 Android 场景
- 课程搜索、章节筛选与语法速查
- 交互式随堂练习
- 本机学习进度和深色模式
- 桌面端与移动端响应式布局

## 本地开发

```bash
npm install
npm run dev
```

生产构建与启动：

```bash
npm run build:vercel
npm run start
```

## 内容规划

课程内容基于 Kotlin 官方知识体系重新组织，并针对 Java Android 开发者增加迁移对照、Android 案例、原理解析、练习和面试表达。
