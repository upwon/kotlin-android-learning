# Kotlin Android 学习站

面向 Java Android 开发者的系统学习网站。从 Java → Kotlin 思维迁移开始，逐步覆盖类型系统、常用写法、JVM 互操作、协程、Flow、Android Jetpack、Jetpack Compose 与生产工程。

## 当前内容

- 11 个知识部分、50 章完整课程
- 第 1～50 章完整讲义、代码示例、动手练习与折叠参考答案
- Hilt、Room、DataStore、WorkManager、Paging 3、Navigation 与测试体系
- Compose 状态、Effect、分页、导航、自适应、无障碍、测试与性能
- 离线优先综合项目、多模块构建与生产发布质量
- 课程搜索、语法速查、交互练习、本机进度和深色模式
- 桌面端与移动端响应式布局

## 本地开发

```bash
npm install
npm run dev
```

生产构建与启动：

```bash
npm run build
npm run start
```

## 内容定位

课程内容基于 Kotlin 与 Android 官方知识体系重新组织，并针对 Java Android 开发者增加迁移对照、Android 案例、原理解析、完整答案和工程取舍。
